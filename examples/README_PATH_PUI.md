# PathPui Examples

Path-based window component for ifckit. These examples demonstrate how to use `PathPui` to create windows with arbitrary outline geometries.

## What is PathPui?

**PathPui** is a pythonic component that creates a window (`IfcWindow`) from a closed `Path` outline. Unlike traditional rectangular windows, PathPui can accommodate:

- Gable walls with sloped edges
- Arched openings
- Custom polygonal shapes
- Organic curves using Path geometry

Each window generated by PathPui includes:

1. **Opening void** — The void that penetrates through the host wall
2. **Frame (lining)** — Aluminum perimeter frame (offset and recessed)
3. **Glazing** — Glass panel inset within the frame

## Examples

### 1. `path_pui_with_wall_graph.py`

**Use case:** Gable wall with filleted corners and path-based window.

Creates a pentagonal wall profile using `PendingWallGraph` and populates it with a path-based window that matches the wall outline.

```bash
python examples/path_pui_with_wall_graph.py
# Output: examples/output/path_pui_example.ifc
```

**Key features:**

- Gable wall with filleted (rounded) corners
- Window geometry driven by the same path
- Parameters:
  - `lining_thickness`: 55mm
  - `lining_depth`: 70mm
  - `glass_depth`: 6mm
  - `wall_thickness`: 300mm (opening depth)

### 2. `path_pui_advanced_shapes.py`

**Use case:** Multiple walls with windows of different outline shapes.

Demonstrates how PathPui adapts to various geometries:

```bash
python examples/path_pui_advanced_shapes.py
# Output: examples/output/path_pui_advanced_shapes.ifc
```

**Walls:**

1. **Large rectangular** — 1.5m × 1.2m opening
2. **Square** — 1.0m × 1.0m opening
3. **Tall narrow panel** — 0.6m × 1.6m opening

All use the same PathPui component with different outline paths.

### 3. `path_pui_custom_component.py`

**Use case:** Using a locally-defined PathPui component from `examples/components/pythonic/`.

Demonstrates how to:

- Define custom components in your project
- Import and use them alongside ifckit's built-in components
- Keep local versions of components for version control

```bash
python examples/path_pui_custom_component.py
# Output: examples/output/custom_path_pui.ifc
```

## Custom Components

A copy of the PathPui component is provided in:

```
examples/components/pythonic/path_pui.py
```

You can:

1. **Customize parameters** — Modify default frame thickness, glass depth, etc.
2. **Extend functionality** — Add new roles (e.g., "Munttin" for window bars)
3. **Version control** — Keep local copies aligned with your project

To use the custom version:

```python
from pathlib import Path as PathlibPath
import sys

# Add to path
sys.path.insert(0, "examples/components")

# Import custom component
from pythonic.path_pui import PathPui as CustomPathPui

# Use as normal
window = PendingWindow(
    path=my_path,
    component_graph="path_pui",  # Registered in component registry
    ...
)
```

## Path Creation

PathPui works with any closed `Path`. Some common patterns:

### Rectangular

```python
from ifckit.geometry import Path, Plane, Vec

path = Path.from_pts(
    [Vec(0, 0, 0), Vec(1, 0, 0), Vec(1, 1, 0), Vec(0, 1, 0)],
    plane=Plane(Vec(0, 0, 0), Vec(1, 0, 0), Vec(0, 1, 0)),
    closed=True,
)
```

### With Filleting (Rounded Corners)

```python
path = Path.from_pts([...], closed=True)
path.fillet([0, 1, 2, 3], radius=0.1)  # Fillet all corners
```

### Using Arc and Line Segments

```python
from ifckit.geometry import Arc, Line

segments = [
    Arc(center=Vec(0, 0, 0), normal=Vec(0, 0, 1), start=Vec(1, 0, 0), angle=90),
    Arc(center=Vec(0, 0, 0), normal=Vec(0, 0, 1), start=Vec(0, 1, 0), angle=90),
    # ... more segments
]
path = Path(segments, closed=True)
```

## Parameters

PathPui accepts these parameters (in `PendingWindow.parameters`):

| Parameter | Default | Unit | Description |
|-----------|---------|------|-------------|
| `lining_thickness` | 55 | mm | Frame inset from path outline |
| `lining_depth` | 70 | mm | Frame depth through the wall |
| `glass_depth` | 6 | mm | Glazing panel thickness |
| `wall_thickness` | 200 | mm | Opening void depth (typically wall thickness) |

Example:

```python
window = PendingWindow(
    path=my_path,
    component_graph="path_pui",
    parameters={
        "lining_thickness": 80,    # Thicker frame
        "lining_depth": 100,
        "glass_depth": 10,         # Thicker glass
        "wall_thickness": 350,     # For thick mass timber
    },
)
```

## Materials

PathPui assigns these materials:

- **Lining** → `ALUMINUM` (frame)
- **Glazing** → `GLASS` (transparent)
- **Opening** → `VOID` (opens to wall)

These can be overridden via `PendingWindow.material_overrides`.

## Troubleshooting

**Issue: "Path must be closed"**

Ensure your Path is created with `closed=True`:

```python
path = Path.from_pts([...], closed=True)
```

**Issue: "Path must be counter-clockwise (CCW)"**

PathPui expects counter-clockwise winding. Most path constructors handle this, but you can explicitly call:

```python
path = path.assert_ccw()
```

**Issue: Window doesn't appear in wall**

- Check that `PendingWindow.plane` is set correctly
- Ensure `component_graph="path_pui"` is specified
- Verify the path is on the same plane as the window insertion
